# catalog 版型的 data.json 格式

給「一大堆結構相同的平行規格」用，例如 99 份 STYLE.md、幾十個範本、一整包 prompt。

## 頂層欄位

| 鍵 | 必填 | 說明 |
|---|---|---|
| `title` | 是 | 例如「lemo-opuscar 風格圖鑑」 |
| `icon` | 是 | 內建圖示名稱（`scripts/icons.py`） |
| `lede` | 否 | 一句話說明 |
| `badges` | 否 | `[{"text": "...", "tone": "warn｜"}]`，放版本與授權 |
| `unit` | 否 | 項目量詞，例如「種風格」「個範本」，預設「個項目」 |
| `searchPlaceholder` | 否 | 搜尋框提示 |
| `flag` | 否 | 一個可篩選的特殊標記：`{"label": "需生圖 ✦", "short": "✦ 需生圖", "note": "詳情視窗裡的說明"}` |
| `sectionNote` | 否 | 詳情視窗最下面的小字 |
| `footer` | 否 | 頁尾說明 |
| `security` | 是 | 安全評估，格式與地圖相同（見 [map-blocks.md](map-blocks.md)），顯示在項目牆下方。render.py 要帶 `--scan <規格庫資料夾>` |
| `items` | 是 | 項目陣列，見下 |

## 每個項目

| 鍵 | 必填 | 說明 |
|---|---|---|
| `id` | 是 | 唯一識別碼，通常是資料夾名，也是網址 hash |
| `name` | 是 | 繁中名稱 |
| `summary` | 是 | 你寫的一句繁中描述（卡片上顯示） |
| `en` | 否 | 原文名稱（原文欄位） |
| `cat` / `catLabel` | 否 | 分類代號與繁中分類名，依項目出現順序決定分類順序 |
| `tagline` | 否 | 上游的一句原文介紹（原文欄位） |
| `palette` / `paletteCount` | 否 | 色碼陣列。只要有任一項目有色碼，卡片就會顯示色條，沒有的顯示斜紋 |
| `kb` | 否 | 原檔大小 |
| `flag` | 否 | true 表示有頂層 `flag` 的標記 |
| `tags` | 否 | 額外的小標籤 |
| `path` | 否 | 原檔絕對路徑（正斜線），詳情視窗會有「開啟原檔」 |
| `openLabel` | 否 | 開啟按鈕文字 |
| `sections` | 否 | `[{"title": "繁中章節名", "en": "原文章節名", "md": "原文 Markdown"}]`，詳情視窗的折疊段落 |

## 抽取的作法

1. 先找上游有沒有索引檔（例如 README 的表格），從那裡拿分類與順序，比自己猜準。
2. 每份規格只抽固定幾個章節，不要整份塞進頁面，控制檔案大小。
3. 繁中名稱與描述集中放一份 `zh_tw.json`，建置腳本缺翻譯就 exit 1。
4. 色碼用 `#[0-9A-Fa-f]{6}` 抓，去重保序，取前 8 個。抓不到就照實顯示斜紋，不要編。
